# Расписание УКСиВТ — данные мини-приложения

Статичное мини-приложение Telegram-бота расписания (`index.html`) и данные для него (`data/`).

- `data/w/<группа>/<понедельник>.json` — недели расписания,
- `data/directory.json` — группы, преподаватели, кабинеты,
- `data/bells.json` — звонки, `data/meta.json` — когда обновлено.

Файлы в `data/` создаёт и обновляет бот автоматически, вручную их править не нужно.
Источник данных — публичное расписание на schedule.uksivt.ru.
